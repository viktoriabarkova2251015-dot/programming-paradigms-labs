Данный публичный репозиторий создан для хранения и демонстрации выполненных лабораторных работ по курсу программной инженерии.

Структура веток репозитория:

1. Ветка main (первая, основная ветка):
   Содержит файлы и исходные коды выполненных лабораторных работ с 1 по 4.

2. Ветка prolog-lab (вторая ветка):
   Содержит исходный код программы, написанной на языке логического программирования Prolog.

3. Ветка dev (третья ветка):
   Резервная ветка для тестирования изменений и промежуточных версий кода.

Инструкция по проверке:
Для просмотра лабораторных работ № 1–4 выберите ветку main. Для ознакомления с программой на Prolog переключитесь на ветку prolog-lab через меню выбора веток в левой верхней части репозитория.
